# My Routine Web V1

Personal, mobile-first PWA.

Included:
- Today / Move / Create / Go / Pack
- Work block 8:30 AM–12:30 PM weekdays
- Strength M/W/F; walks Tue/Thu; Create 15 min Tue + 30 min Thu
- Persistent weekly progress
- Tournament Mode
- Persistent tournament packing list
- Offline-capable PWA

Google Calendar:
Calendar is intentionally not authenticated inside this source package. After deployment to a stable HTTPS URL, configure Google Calendar read-only OAuth. Never embed a Google client secret in browser JavaScript.

Local preview:
`python3 -m http.server 8080`
then open `http://localhost:8080`.
